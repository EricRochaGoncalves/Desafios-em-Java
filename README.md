# 🚀 Desafios de Programação em Java - Orientação a Objetos
Este repositório reúne meus desafios e exercícios práticos em Java, focados em Orientação a Objetos (OO) e no aprendizado contínuo da linguagem.

# 💡 Sobre este desafio: Sistema de Conta Bancária
Para sair da zona de conforto e colocar em prática conceitos básicos e essenciais da OO, desenvolvi um sistema simples que simula uma conta bancária, trabalhando com:

-- Classes e objetos

-- Construtores

-- Atributos privados e encapsulamento

-- Métodos para depósito, saque e consulta de saldo

-- Validações para evitar operações inválidas (ex: saque maior que o saldo)

# Como foi pensado o sistema?
Criei a classe ContaBancaria com os atributos privados titular e saldo (chamado de "salário" no código por hábito).

Implementei um construtor para inicializar o objeto com dados válidos já na criação.

Adicionei métodos para realizar depósitos, saques (com validação) e exibir saldo.

Testei o sistema com uma classe Main simulando operações reais.

# 💡 Desafio adicional: Calculadora Simples
Recebe dois números e permite escolher uma operação: soma, subtração, multiplicação e divisão.

Implementa tratamento para divisão por zero.

Utiliza Scanner para entrada de dados e estruturas condicionais para decidir a operação.

# 🚀 Próximos passos no aprendizado OO
Estudar Herança: reaproveitar atributos e métodos entre classes.

Explorar Polimorfismo: métodos com comportamentos diferentes conforme o contexto.

Usar Interfaces: garantir contratos entre classes para padronizar comportamentos.
